# A time series of NDVI in Navarre (Spain)

Geographically projected `RasterBrick` object of the normalized
difference vegetation index (NDVI) in Navarre.

## Format

The `RasterBrick` contains 6 images, from the 2nd to the 4th of August
in 2017 and 2018. The `RasterBrick` coordinates are in the Sinusoidal
projection:

- name:

  layer names contain the date of the image in the format "`YYYYJJJ`"

- size:

  each layer contains 113 rows and 105 columns
